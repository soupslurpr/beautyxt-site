The website, specifically

Website privacy

This page describes the website. For the Android app, see files and privacy.

No analytics or embedded services

This site contains no JavaScript, analytics, tracking pixels, or advertising. It doesn’t set cookies or use local storage. Images and styles are served from this site; fonts use what’s already installed on your device.

Hosting

The published website is hosted on GitHub Pages. GitHub receives requests needed to serve the site and logs visitors’ IP addresses for security purposes, as described in its privacy statement.

External links

Links to GitHub, Accrescent, Matrix, and other websites take you to services with their own privacy policies. Those services are not embedded in this page. This website asks browsers not to send a referrer when following links.

Questions

You can contact the developer with questions about this website.
