Your files, in your hands

A text editor.
Not another cloud.

BeauTyXT works with the files you choose, where you choose to keep them. There’s no app-private document library to move into—or out of.

How it works ↗
No Internet permission
The app cannot directly connect to the Internet. It doesn’t fetch remote images or other document resources.
Files stay at their source
Compatible files save automatically. New and received text stays in memory until you choose Save.
Isolated processing
Rust workers process documents in separate, restricted Android processes. Rendering doesn’t execute document scripts.

Your storage provider may sync files. Opening a link hands it to another app. Unsaved content has no recovery copy, so save what you want to keep.

The useful details

Know what you’re opening.

Plain files. Clear boundaries. No surprises hidden in the fine print.

Which files can I open?

UTF-8 plain text and Markdown, up to 256 MiB. Open files through Android’s file picker or receive supported content from another app. Recognized filename extensions take priority over the reported file type.

Markdown rendering accepts up to 16 MiB, with additional complexity limits. Larger files remain available in source view. The interface is currently English-only.

What does Markdown rendering support?

Headings, lists, tables, task lists, code blocks, alerts, footnotes, and a supported HTML subset, plus a bounded subset of TeX math and Mermaid diagrams. Unsupported content remains visible as source.

This is a native document renderer, not a web browser. Images appear as alternative text. CSS, scripts, general HTML layouts, DOCX, and Typst are not supported. See the supported content and limits.

How does saving work?

Compatible source files save automatically after edits. If a storage provider cannot support verified saving, the file opens view-only; Save as editable creates a compatible source without changing the original.

New documents and received text remain in memory until you save. There are no private backup or recovery files. Unsaved content is lost if you close its session or Android ends the app process.

BeauTyXT checks the source before and after saving and reports conflicts or uncertain writes. Storage providers don’t universally support atomic writes: another app can race a save, and an interrupted write can leave a file incomplete.

Can I read something shared from an AI assistant?

Yes. Share plain text or Markdown, or open a saved file, and read it independently of the conversation it came from. Edit it, keep it, or pass it to someone using a different app.

There’s no built-in assistant or model service. BeauTyXT displays the document; it doesn’t verify the accuracy of its contents.

What can I share or print?

Share saved files through their existing provider, or share up to 128 KiB of UTF-8 text directly. QR transfers accept up to 1,536 UTF-8 bytes; NFC messages up to 256 KiB, with writes also limited by the tag’s capacity. QR images can be saved as lossless WebP or PNG.

Print source text or formatted Markdown, including supported math and diagrams, or choose Save as PDF in Android’s print dialog. Adjust each margin, font and size, filename header, and page numbers. PDFs have selectable text and basic structure, but not full PDF/UA accessibility.

Which permissions does it use?

Camera access is optional and used for scanning QR codes. NFC is used for reading and writing tags on devices that support it. BeauTyXT has no Internet permission and doesn’t request access to your entire file collection.

Android grants access to files you choose or receive. Your independent keyboard and storage provider have their own access and privacy behavior.
